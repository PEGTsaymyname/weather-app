# OpenWeather App 🌤️

Простой Python-скрипт для получения текущей погоды в любом городе через OpenWeatherMap API.

## Функционал
* Автоматическое определение координат города (Geocoding API).
* Вывод реальной температуры и температуры «по ощущениям».
* Отображение погодных условий (ясно, дождь, облачно и т.д.).
* Безопасное хранение API-ключа в переменных окружения (`.env`).

## Стек технологий
* Python 3
* Requests (работа с API)
* Python-dotenv (работа с переменными окружения)
